# QUORA Clone

A simple CRUD based Quora Clone built using Node.js, Express.js, EJS, HTML, and CSS.
Users can create, read, edit, and delete posts with a clean responsive UI.

# 🚀 Features
Create New Posts
View All Posts
View Post Details
Edit Existing Posts
Delete Posts
Unique ID generation using UUID
Responsive UI
RESTful Routing
Method Override for PATCH & DELETE requests
# 🛠️ Tech Stack
Node.js
Express.js
EJS
HTML5
CSS3

⚙️ Installation

# Clone the repository:

git clone <your-repository-link>

Move to project folder:

cd project-name

# Install dependencies:

npm install

Start the server:

node index.js

OR

nodemon index.js
🌐 Run Locally
Open browser and visit:
http://localhost:3000/posts
